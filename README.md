## 🎯 Features

- ⚡ **Next.js App Router** with static HTML export for instant page loads
- 🤖 **AI & LLM Model Discoverability**:
  - `llms.txt` and `llms-full.txt` standard files for ChatGPT, SearchGPT, Claude, Perplexity, and Gemini indexing
  - Specialized AI crawler directives in `robots.txt`
- 🔍 **Top-Tier Global & Local Search Engine Dominance**:
  - Full Open Graph & Twitter Cards (`@hamzariopk`)
  - Rich JSON-LD Structured Data (`Person`, `WebSite`, `ProfessionalService`, `ItemList`, `FAQPage`)
  - Geo-targeting meta tags (`geo.region`, `geo.placename`, `geo.position`, `ICBM`)
  - XML Sitemap and Robots.txt configured for all major search engines
  - PWA Web App Manifest
- 📱 **Mobile-First & Ultra Responsive**: Tailored for smartphones, tablets, and desktops
- 💼 **Interactive Project Showcase**: Lightweight architecture linking directly to live GitHub Pages and Vercel demos
- 📧 **Direct Contact Integration**: Working EmailJS contact form

## 🚀 Getting Started

### Prerequisites

- Node.js 20+ installed

### Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Production Build

```bash
# Build and export static site to /out
npm run build
```
